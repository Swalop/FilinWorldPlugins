# FilinPrivates
Система приватных территорий для Filin World (Paper 1.16.5).

## v1.1.0

### База данных
Плагин поддерживает **SQLite** (по умолчанию) и **MySQL**.

#### SQLite (ничего настраивать не надо)
1. Установи плагин
2. В `config.yml` убедись: `database.type: sqlite`
3. Перезапусти сервер
4. Файл `regions.db` создастся автоматически в папке плагина

#### MySQL
1. Создай базу данных на хостинге (например, `filin`)
2. В `config.yml` пропиши:

```yaml
database:
  type: mysql
  host: localhost        # адрес MySQL сервера
  port: 3306             # порт
  database: filin        # название базы
  user: root             # пользователь
  password: 'твой_пароль' # пароль
  ```

## v1.0.3
### Новое
- GUI-меню `/rg menu` — список приватов, телепорт, удаление
- Интеграция с WorldGuard — создание, удаление, флаги настоящих WG-регионов

- Партиклы границ привата при входе
- `/rg up` и `/rg down` работают **до** создания привата (меняют высоту выделения)
- Таб-дополнение для всех команд

### Команды
| Команда | Описание |
|---------|----------|
| `/rg claim <название>` | Создать приват |
| `/rg up/down <число>` | Изменить высоту выделения (до создания) |
| `/rg add <ник>` | Добавить участника |
| `/rg addowner <ник>` | Назначить со-владельца |
| `/rg remove <ник>` | Убрать игрока |
| `/rg delete <название>` | Удалить приват (только владелец) |
| `/rg info` | Информация о привате |
| `/rg list` | Список ваших приватов |
| `/rg menu` | GUI-меню |
| `/rg flags` | Список доступных флагов |
| `/rg flag <флаг> <on/off>` | Установить флаг (ADMIN+) |
| `/rg config reload` | Перезагрузить config.yml (ADMIN+) |
| `/rg help` | Подробная справка |
